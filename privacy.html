Privacy

Applies to all Sentiora applications

Sentiora runs no service that your data passes through. There is no Sentiora account, no analytics, no advertising identifier, and no server of ours between you and your files.

That is not the same as saying the applications never use the internet. Some of them can, for things you switch on yourself. This page lists every one of those, so you can decide about each.

What is stored, and where

Everything an application remembers is written to your own computer, in its own folder under AppData\Local — settings, licence, health history, reports and logs. Disk Manager uses SentioraDiskManager, and each product has its own so they cannot overwrite one another.

None of it is uploaded. If you delete the folder, it is gone; we hold no copy, because there is nowhere for a copy to be held.

What can connect outward

Each of these is off, optional, or something you configure yourself. Nothing here is enabled silently.

The AI advisor

Every product that offers AI does it through a provider you pick and a key you supply — Claude, ChatGPT, Gemini, Mistral, Groq, DeepSeek, or a model running on your own machine through LM Studio or Ollama. The request goes from your computer straight to that provider. It does not pass through us, and we never see your key or the answer.

The key is stored encrypted on your PC. What is sent is the material the feature needs: in Disk Manager, the readings it has taken from your hardware; in DocPilot, the text of the document you loaded. Whatever the provider then does with it is governed by their terms, not ours, which is why you get to choose which one it is.

Leave the provider set to Offline and Disk Manager sends nothing at all — its own checks still produce the health verdict. DocPilot's assistant falls back to local heuristics with no key and no network.

Email alerts

Disk Manager can email you when a drive starts failing. It sends through your own mail server, using SMTP settings you enter. The message goes from your computer to your provider; we are not a party to it.

The version check

Disk Manager can look at sentiora.dev/versiune.json once a day to see whether a newer release exists. It is a plain file request: it sends no identifier, no licence number and nothing about your machine. A web server sees that a file was requested, as it would for any download. This can be turned off.

Driver lookups

Driver Finder queries Microsoft's own sources — Windows Update and the Microsoft Update Catalog — using the hardware ID of the device you are asking about. Nothing is sent to Sentiora, and nothing is fetched from third-party driver sites.

The licence stop list

Applications read a small signed file from sentiora.dev once a day, listing licences that have been withdrawn. It is a plain file request that carries no licence number and no identifier: the file says which licences are void, and your computer decides locally whether yours is among them. If it cannot be reached, nothing happens.

Activation, for multi-seat licences only

Sentiora ComicBubble's Studio and Enterprise editions allow a set number of computers, and enforcing that requires counting them. Those editions send the licence key, the buyer's email and an identifier for the machine to an activation service, and can release a seat again when you move to another computer. The Personal edition does none of this — its licence is verified offline.

Licences

Most Sentiora licences are signed in advance and verified on your computer with a public key built into the application. Buying does not create an account. DocPilot's licence is tied to the buyer's email address, and only a hash of that address is inside the key — the key itself reveals nothing about you.

What we never do

  • No Sentiora account, ever, for any product.
  • No analytics, usage tracking or crash reporting sent automatically. If you send a fault report, it is because you pressed a button and could read it first.
  • No advertising, and no advertising identifiers.
  • No selling, sharing or brokering of anything. There is no data to sell, because none is collected.
  • No silent connections. Everything above is either off by default or something you set up.

Children

These are tools for maintaining computers, writing documents and drawing comics. They are not directed at children, and they collect nothing from anyone.

Changes

If an application ever gains a feature that sends something new, this page changes before that release ships, not after.
