/ Capabilities

A disc you can trust afterwards.

Burning is irreversible, so the useful part is knowing what actually landed on the disc. Verification reads every file back and compares it to the source, byte by byte, and tells you plainly if anything differs.

01 / BURN

Data, ISO and audio

Add files and write them to disc with verification afterwards. Write an ISO image — a bootable ISO produces a bootable disc. Build a Red Book audio CD straight from MP3, FLAC or WAV: the LAME and FLAC encoders ship inside the package, with their licences, so nothing is downloaded.

02 / SPLIT

MultiDisc for what will not fit

When a set of files is larger than the media, it is split across as many discs as it needs. A visual panel shows the real state of the disc in the drive — how much is used and how much is left — before anything is written.

03 / IMAGES

Create, convert and extract ISO

Build an ISO from files without burning anything. Convert BIN, IMG and NRG into a standard ISO. Pull individual files back out of an image. Erase rewritable discs when you want to start again.

04 / PROTECT

Encryption and checksums

Lock files with a password using AES-256-GCM, which carries an integrity check: if the file was later corrupted or tampered with, it says so rather than handing back damaged data. Checksums in CRC32, MD5 and SHA-256 for anything you need to compare.

05 / SURVIVE

Reed-Solomon protection

Discs rot, scratch and age. Reed-Solomon adds redundant data alongside the originals so a partially damaged file can be reconstructed instead of lost — the difference between an archive and a coaster.

06 / READABLE

Eleven languages, all the way down

English, Chinese, Hindi, Spanish, French, Arabic, Bengali, Portuguese, Russian, German and Romanian, switched instantly. Everything is translated, including the log that scrolls while a disc is being written. No ads, no telemetry, no account — it all stays on the machine.

/ Release

Two editions, and the honest difference.

The desktop edition talks to the drive directly, which Windows only permits with administrator rights. That is what makes disc copying, data recovery, aggressive CD reading, audio extraction, raw writing and bootable USB possible. Packaged Store apps cannot request those rights, so the Store edition does not offer those tools and does not show them either — you will not buy something you do not receive.
