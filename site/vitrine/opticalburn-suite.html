/ Capabilities

A disc you can trust afterwards.

Burning is irreversible and discs do not last forever. Both problems have the same answer: read the disc back and check it against what should be there. That is what turns a burn into an archive — and what makes it possible to rescue one that has already started to go.

01 / BURN

Data, ISO and audio

Add files and write them to disc with verification afterwards. Write an ISO image — a bootable ISO produces a bootable disc. Build a Red Book audio CD straight from MP3, FLAC or WAV: the LAME and FLAC encoders ship inside the package, with their licences, so nothing is downloaded.

02 / RESCUE

Get back a disc that is failing

Recovery reads a scratched or ageing disc as stubbornly as the drive allows and saves what is still readable, instead of stopping at the first bad sector. Where Reed-Solomon protection was written alongside the files, damaged parts can be reconstructed outright rather than merely salvaged.

03 / VERIFY

Check the disc, not your luck

Compare a disc against its ISO bit by bit, and read the drive's real report on the media in it: blank or written, the next writable address, how much room is actually left. It is the difference between believing a burn worked and knowing it did.

04 / COPY

Duplicate, rip and make bootable USB

Copy a disc, or lift an audio CD into MP3, FLAC or WAV. Write a bootable USB stick for the machine that has no optical drive at all — the usual reason an old disc becomes unreadable is that nothing left can read it.

05 / IMAGES

Create, convert, extract and split

Build an ISO from files without burning anything. Convert BIN, IMG and NRG into a standard ISO, or pull individual files back out of an image. MultiDisc splits a set that is larger than the media across as many discs as it needs, and rewritable discs can be wiped clean.

06 / PROTECT

Encrypted, checksummed, and yours

Lock files with AES-256-GCM, which carries an integrity check: if the file was later corrupted or tampered with, it says so instead of handing back damaged data. Checksums in CRC32, MD5 and SHA-256. Eleven languages, translated all the way down to the log that scrolls during a burn. No ads, no telemetry, no account.

/ Release

It talks to the drive directly.

Copying, recovery, audio ripping, raw writing and disc diagnosis all need to send commands straight to the drive, which Windows only permits with administrator rights. That is the one thing it asks of you, and it asks once. No ads, no telemetry, no account, and nothing passes through Sentiora.
