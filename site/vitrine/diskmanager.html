01 / Health · S.M.A.R.T.

A drive that is doing well.

Health, wear, spare capacity, media errors, unsafe shutdowns, temperature and hours powered on — read straight from the drive, with a trend that shows whether the reading is steady or moving.

02 / A drive that is failing

Back up now, not later.

Over seven million reallocated sectors, 32 pending, and cable CRC errors. Disk Manager says what that means in words — back up now, the disk can fail at any moment — instead of leaving you to interpret raw numbers.

03 / Surface scan

Read every sector, write nothing.

Green is fine, yellow is slow, red would not read. Sample the disk in a few minutes or walk every sector of it. When bad sectors turn up it says what to do next: back the data up first, then let Check and repair fence them off.

04 / Check and repair

Read-only unless you say otherwise.

A verify-only check leaves the volume usable and is safe at any time. Repairing bad sectors modifies the disk, so it stays behind ARMED mode until you deliberately turn it on.

05 / Benchmark

How fast the drive really is.

Sequential for large files, random 4K for programs, 64K for games, 1 MB for video work. A read test — it writes nothing to the drive.

06 / Ask about this computer

An answer about your machine.

The advisor starts from what the application actually read on this PC. Here it picks the failing drive out of four, explains what reallocated sectors mean, and says what to do first.

07 / Your provider, your key

You choose who answers.

Built-in offline answers need no key at all. If you want a stronger model, connect Claude, ChatGPT, Gemini, Mistral, Groq, DeepSeek, a local LM Studio or Ollama server, or any custom endpoint. The key is encrypted and stays on your PC.

08 / System detection

Proof it read the machine correctly.

CPU, memory, Windows version, BIOS date, every drive with the SMART method used to read it, and the graphics card. Anything it could not read is flagged rather than quietly skipped.

09 / Driver Finder

Official sources only.

It checks Windows Update and the Microsoft Update Catalog using each device's own hardware ID. Drivers can be backed up or installed from a folder. Nothing is ever pulled from a third-party driver site.

10 / DLL Doctor

For the error that stops a game starting.

Paste the error — or just the DLL name — and it works out which official package is missing. It installs Microsoft and vendor packages only; downloading loose DLL files from the web is how machines get infected.

11 / Automated test

Checking the application, not your patience.

Runs every function against the drives you tick, in the background or with the windows shown. Bad sectors found during it are reported as a disk warning, not as an application fault, and the AI can review the report at the end.

12 / ARMED mode

The safety catch is deliberate.

The application starts in simulation every time. Formatting, initialisation, secure erase, cloning and write-based tests do nothing until ARMED is on — and the banner stays red for as long as it is.

13 / Disks and tools

Everything in one row.

Health report as a PDF, health history over time, system detection, Driver Finder, DLL Doctor — and the two that change data, secure erase and format, sitting apart on their own line.

/ Capabilities

Days, or years. It tells you which.

Other tools show you SMART attributes and leave you to work out what 7,275,432 reallocated sectors means. Disk Manager reads the same data and answers in words: healthy, or back up now. Everything that could change your data sits behind a second switch.

01 / HEALTH

How long this drive has left

Health, wear, spare blocks, media errors, unsafe shutdowns and temperature, read from SMART or the NVMe log. Above them sits the line people actually want — life left, one to three years or days to weeks — with a trend that shows whether the reading is holding steady or sliding. The history is kept locally, so a drive that is slowly going shows its slope instead of a single reassuring snapshot.

02 / SURFACE

Find the bad sectors before your files do

Sample the disk in a few minutes, or walk every sector of it. The map fills in as it goes: green for fine, yellow for slow, red for would not read. It writes nothing during the scan, and when bad sectors turn up it says what to do next — copy the data off first, then fence them off so Windows stops using them.

03 / STORAGE

Speed and space, made concrete

Benchmark a drive with a test file, then use Space Analyzer to see which folders and files are actually using the room. Windows' own maintenance is here too: run a check disk, or optimize a drive — trim on an SSD, defragment on a hard disk — without hunting for the right dialog.

04 / SAFETY

It cannot wipe the wrong disk

The application opens in simulation every single time. Cloning, formatting, initialising, secure erase and write-based tests do nothing at all until you switch ARMED on — and then a red banner stays across the window for as long as it is, with a confirmation that names the drive by model before anything happens.

05 / SYSTEM

Drivers, DLLs and hardware context

Review installed driver versions, find official update sources, identify missing Microsoft runtime packages and check exactly what the application detected on the PC.

06 / MONITORING

It finds you when you are not looking

Tray indicators and temperature alerts run quietly; health reports export as PDF. Alerts can go to your own email as well, so a drive that starts failing on Friday does not wait until Monday. The advisor is optional and answers about this machine using the readings already taken — built in without a key, or through Claude, ChatGPT, Gemini, Mistral, Groq, DeepSeek or your own local model if you want a stronger one. It can suggest read-only tools; it cannot run anything that changes data.
